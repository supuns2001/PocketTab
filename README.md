# 🔖 PocketTab

A lightweight Chrome Extension to save web pages for later reading with custom notes and instant search.

## 🌟 Overview
**PocketTab** helps you bookmark important web pages with personalized notes. All data is saved securely in your browser's local storage (`chrome.storage.local`).

## ✨ Features
- ⚡ **Auto-Detect Tab**: Automatically captures current page title & URL.
- 📝 **Custom Notes**: Add notes explaining why you saved the page.
- 🔍 **Instant Search**: Filter saved pages and notes in real time.
- 🔒 **Local & Secure**: 100% private, no external server or account needed.
- 🚀 **1-Click Open**: Launch saved links in a new tab.

## 📦 How to Install
1. Open Google Chrome and go to `chrome://extensions`.
2. Enable **Developer mode** (top-right toggle switch).
3. Click **Load unpacked** (top-left) and select the `PocketTab` project folder.
4. Pin 📌 **PocketTab** to your browser toolbar for quick access.

## 🎯 How to Use
1. Click the **PocketTab** icon on any web page.
2. Add your note and click **Save Page for Later**.
3. Use the search bar to find notes or click **Open** to visit saved links.

## 💻 Tech Stack
HTML5 • CSS3 • JavaScript (ES6+) • Chrome Extension API (Manifest V3)
